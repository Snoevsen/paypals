# PayPals

## Getting Started

### Prerequisites

- **Android Studio**
- **JDK 17+** 
- A **Firebase project** with **Authentication** (Email/Password enabled) and **Cloud Firestore** enabled.

---  

### Add Your `google-services.json`

1. Open the [Firebase Console](https://console.firebase.google.com/) and select your project.
2. Add an Android app with package name **`com.sdu.paypals`**.
3. Download the **`google-services.json`** configuration file.
4. Place the file inside the `app/` directory
